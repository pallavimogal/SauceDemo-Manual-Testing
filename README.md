# SauceDemo — Manual Testing Portfolio

## Project Overview
This is an independent manual QA portfolio project using the SauceDemo practice e-commerce application. The project demonstrates test planning, test case design, functional testing, defect documentation, and test execution reporting.

## Application Under Test
- Application: SauceDemo (Swag Labs)
- URL: https://www.saucedemo.com/
- Type: Web application

## Planned Testing Scope
- Login and authentication
- Product catalog and sorting
- Shopping cart
- Checkout workflow
- Form validation and negative testing

## Testing Techniques
- Functional testing
- Positive and negative testing
- Boundary value analysis
- Equivalence partitioning
- Regression testing

## Tools
- GitHub: Project documentation and version control
- Spreadsheet software: Test cases and execution reports
- Browser developer tools: Investigation and evidence

## Project Status
In progress — Test planning and preparation.

## Note
This is an independent learning project and is not affiliated with Sauce Labs or Swag Labs.
